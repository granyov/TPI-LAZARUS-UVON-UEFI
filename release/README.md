# Метаданные сборки

Здесь лежат только описания: состав FIT с контрольными суммами всех девяти
компонентов и протокол испытаний на физической плате.

**Собранных образов и заводского загрузчика здесь нет.** Из девяти компонентов
FIT наши только два — `u-boot` (BL33) и `fdt-1`; остальные семь представляют
собой двоичные payload'ы TF-A и OP-TEE от Rockchip и Forlinx, а
`MiniLoaderAll.bin` байтово идентичен заводскому. Их условия использования
принадлежат правообладателям, поэтому открыто они не распространяются.

Собрать прошивку можно полностью — порядок в [`docs/BUILD.md`](../docs/BUILD.md).
Vendor-входы задаются путями и сверяются по SHA-256 из того же документа, так
что подставляются свои, полученные законным путём.

Сотрудникам TPI собранные образы доступны в закрытом репозитории
`TPI-LAZARUS-UVON-Bootchain`.
